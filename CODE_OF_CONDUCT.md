# Code of Conduct

Backbloom follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project.

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep discussions about the
work. Harassment, insults, personal attacks and publishing others' private information are not acceptable in
issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

If someone's behavior concerns you, report it privately to the maintainer through
[GitHub's private vulnerability reporting form](https://github.com/valburkin/Backbloom/security/advisories/new)
(select it even though it isn't a security issue; it reaches the maintainer only), or use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. Reports are handled confidentially. The maintainer may remove comments, lock threads or block participants
who break this code, following the Covenant's enforcement guidelines.
