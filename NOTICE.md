# Notice and credits

Backbloom is an ambient lighting app derived from **[HyperHDR](https://github.com/awawa-dev/HyperHDR)** by awawa-dev,
copyright (c) 2020-2026 awawa-dev, licensed under the MIT License. HyperHDR is itself derived from
**[Hyperion.ng](https://github.com/hyperion-project/hyperion.ng)**, copyright (c) 2014-2020 Hyperion Project, also MIT.

The Backbloom backend (`backend/`) is a C# port of HyperHDR's C++ code: LED layout and image-to-LED mapping, color
processing and calibration, smoothing, effects and music analysis, black border detection, HDR tone mapping, the LED
device drivers, settings import and more. The doc comments name the HyperHDR source file each part was ported from.
